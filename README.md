 ###Что нового я узнал о классе Process:
   Я узнала, что класс `Process` из пространства имён `System.Diagnostics` позволяет получить объект, представляющий текущий запущенный процесс. С его помощью можно узнать уникальный идентификатор процесса (`Id`) , который этот процесс использует в данный момент (`WorkingSet64`). Это даёт более прямой доступ к данным процесса по сравнению с классом `Environment`.

###Сравнение памяти программы и Диспетчера задач:

###Почему значение памяти может немного изменяться:
    Объём памяти процесса не является постоянной величиной, потому что во время работы программы .NET и операционная система продолжают выполнять фоновые задачи: сборка мусора (Garbage Collection), загрузка дополнительных библиотек, буферизация вывода в консоль. Сама Windows может временно выгружать неиспользуемые страницы памяти процесса на диск или обратно, что также влияет на показатель WorkingSet.
